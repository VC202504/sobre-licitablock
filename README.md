# LicitaBlock

Plataforma white label e multi-inquilino para municípios realizarem licitações eletrônicas com a própria identidade visual, integrada ao Portal Nacional de Contratações Públicas (PNCP).

**Situação:** Em desenvolvimento

## O que faz

- Rito completo: proposta, lances, julgamento, habilitação, adjudicação e homologação
- Livro-razão da sessão pública: cada ato encadeado por hash, com verificação de integridade
- Sala de disputa para o pregoeiro e área do fornecedor
- Identidade visual de cada município por tokens de tema
- Integração com o PNCP

## Tecnologia

Next.js, Prisma, PostgreSQL
